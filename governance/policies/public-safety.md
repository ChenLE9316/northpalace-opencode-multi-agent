# Public Safety Policy

The public repository is a curated projection, not an export of a private workspace.

Do not publish credentials, authentication material, private keys, personal contact information, user-home paths, machine identifiers, private network addresses, raw sessions/logs, private screenshots, private backlog/evidence, workstation/global mirror state, private provider routing, private plugin/MCP configuration, backups, or private repository references.

Use example values only when an example is necessary. Prefer omission over redaction when the private detail does not improve the public architecture demonstration.

A later deletion does not erase Git history. Sensitive committed content requires incident handling, credential rotation when applicable, and history cleanup as appropriate.
