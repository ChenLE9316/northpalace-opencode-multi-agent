# np-autonomous-loop

1. Inspect user goal, README, backlog, recent outcomes and actual code state.
2. Select one actionable outcome; capture reason, dependencies and definition of done.
3. Prefer direct execution for small tasks, delegation for specialized/parallel work.
4. Run implementation/checks and record evidence; report blockers instead of spinning.
5. Repeat while useful authorized objectives remain. No arbitrary step count, but cap fan-out.
