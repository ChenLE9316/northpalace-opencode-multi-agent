# Public Projection Boundary

This repository is intentionally **not** a synchronized copy of a private NorthPalace workspace.

The showcase preserves the architecture that is useful for public review:

- L1–L4 role topology and delegation boundaries;
- representative commands and reusable skills;
- task/result/evidence contracts;
- runtime, risk/HITL, verification, and public-safety policy;
- deterministic privacy and structure validation.

The showcase intentionally omits operational/private surfaces:

- real model/provider routing and account-specific limits;
- plugins, MCP servers, credentials, private endpoints, and workstation configuration;
- global OpenCode mirror/sync state;
- real backlog items and operational timestamps;
- runtime evidence, traceability snapshots, raw sessions/logs/screenshots;
- backups and private repository/workspace references;
- the large internal design/research corpus.

Omission is a security and privacy feature, not an architectural limitation. Public examples should demonstrate the control model without reconstructing a developer's private environment.
